=== PAGE 4 ===
What is clustering?

• A way of grouping together data samples that
 are similar according to some criteria
• A form of unsupervised learning
    • Don’t need testing data demonstrating how the data
     should be grouped together
• It’s a method of exploratory data analysis
 (EDA)
    • looking for patterns or structures in the data that are
     of interest
    • no explicit labels; the clusters may need further
      interpretation.

Linkage in Hierarchical
Clustering

• We already know about distance measures
 between data items, but what about between a
 data item and a cluster or between two
 clusters?
• We just treat a data point as a cluster with a
 single item, so our only problem is to define a
 linkage method between clusters

=== PAGE 25 ===
Average Linkage

• Average linkage is defined as follows:
    • Each cluster ci is associated with a mean vector i
    which is the mean of all the data items in the cluster
    • The distance between two clusters ci and cj is then
      just d(i, j )

=== PAGE 27 ===
Ward’s Method

• Consider merging two clusters, how does it
 change the total distance from centroids?





 1. Find the centroid of each cluster.
 2. Calculate the distance between each object and its cluster’s centroid.
 3. Calculate the sum of squared differences from Step 2.
 4. Add up all the sums from Step 3.

=== PAGE 30 ===
K-means Clustering


• Choose the number of clusters k
• Initialize cluster centers 1,… k
    • Randomly pick k data points and set cluster centers
     to these points
• For each data point, compute the cluster center it is
  closest to (using a distance measure) and assign the
  data point to this cluster
• Re-compute cluster centers (mean of data points in the
  cluster)
• Stop when there are no new re-assignments

=== PAGE 40 ===
Silhouette Score


    • Measures how similar an object is to its own cluster
     (cohesion) compared to other clusters (separation).
    • Range: -1 to +1
    • +1: Perfectly clustered. 0: Overlapping clusters. -1:
    Wrongly assigned.

=== PAGE 41 ===
Summary

• Clustering discovers natural structure in unlabeled
 data by grouping similar samples.
• Different methods make different assumptions about
 what defines a cluster; therefore, the choice of
 distance metric and clustering algorithm matters.
• K-means is simple and widely used, while hierarchical
 and other extensions can provide more flexible cluster
  structures.
• Although clustering is unsupervised, the resulting
  cluster assignments or representations can be used as
  features or pseudo-labels for downstream
  classification.
